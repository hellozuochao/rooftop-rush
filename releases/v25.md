# Rooftop Rush v25 — 第一视角与道具视觉

- 改用第一人称视角，移动方向跟随视线，滑铲时视点降低。电脑按 Tab 可释放鼠标操作菜单。
- 滑铲通道移除文字标牌，改用低开口、黄色警示纹、地面导向和滑铲人形图案。
- 14 种道具使用对应功能的模型；地面拾取物、背包图标和使用特效统一，拾取奖励与显示模型一致。
- 增加持续状态图标、护盾、导弹拖尾、弹簧、陷阱、烟雾、净化与冲击波视觉反馈。
- 设置显示游戏版本与当前服务器的 Roblox 平台版本；构建记录完整源码提交。
- 本地 Studio 测试发布后同步 GitHub Release，附件回执记录 Roblox 平台版本与文件 SHA-256。

验证范围见 TEST-REPORT-V25.md。Studio 设备模拟不等于真机触屏、低端设备或弱网络测试。
只有随附成功 Roblox 发布回执的正式 Release 表示双平台发布完成。
