## Validation

Release preparation is not a live deployment. Offline compilation, map checks,
logic tests and publication-recovery tests are automated. Before dispatching the
publication workflow, the maintainer must test this exact commit in Studio,
including settings on narrow screens and multiplayer server version display.
Real-device and live-server checks are separate from offline CI.
